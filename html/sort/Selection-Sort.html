Selection Sort

Selection sort is an in-place comparison sort prized for its simplicity and its tiny number of writes — handy when memory or write cost is the constraint. It is usually slower than insertion sort.

It splits the list into a sorted front and an unsorted rest. Each pass scans the unsorted part for its smallest element and swaps that to the front, growing the sorted region by one.

Complexity

  • Best, average & worst case: O(n²)
