Heap Sort

Heap sort is a comparison sort that behaves like a smarter selection sort: rather than scanning the unsorted region for the largest value each time, it keeps that region in a heap so the maximum is always at the root.

It runs in two phases: first build a max heap from the data; then repeatedly swap the root (the largest value) to the end and sift the heap down, shrinking the heap each time until the array is sorted.

Complexity

  • Best, average & worst case: O(n log n)
  • Space: O(1)
