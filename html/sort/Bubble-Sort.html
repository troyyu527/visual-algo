Bubble Sort

A bubble sort (or sinking sort) is the simplest comparison sort. It is slow in practice and used mainly to teach — real code reaches for quick sort, merge sort, or Timsort.

It repeatedly walks the list and compares each pair of adjacent elements, swapping them whenever they are out of order. Every pass "bubbles" the largest remaining value to the end; when a full pass makes no swaps, the list is sorted.

Complexity

  • Best case: O(n) — already sorted
  • Average & worst case: O(n²)
