Merge Sort

Merge sort is an efficient, general-purpose, divide-and-conquer sort. It is stable — equal elements keep their original order — and runs in O(n log n) time in every case.

It splits the list down to single elements (a one-element list is already sorted), then repeatedly merges those pieces back together in order until a single sorted list remains.

Complexity

  • Best, average & worst case: O(n log n)
  • Space: O(n)
