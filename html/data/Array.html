Array

An array is a collection of elements kept in one contiguous block of memory, each identified by an index. Because every element's address is computed directly from its index, any element can be read or written in constant time — O(1) random access.

Operations (as in JavaScript)

  • Push: add an element at the end.
  • Pop: remove the element at the end.
  • Unshift: add an element at the front.
  • Shift: remove the element at the front.

The price of that fast indexing is costly restructuring: inserting or removing anywhere but the end shifts every following element — an O(n) operation, which is exactly where linked structures do better.
