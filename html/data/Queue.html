Queue

A queue is a linear collection with two ends: elements are added at the rear and removed from the front, just like people waiting in line.

Operations

  • Enqueue: add an element at the rear.
  • Dequeue: remove and return the element at the front.

The first element enqueued is the first one dequeued — first in, first out (FIFO).

Priority queue: a variant where each element carries a priority and the highest-priority one is served first (ties keep arrival order). It is most efficiently backed by a heap.
