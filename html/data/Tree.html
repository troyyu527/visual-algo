Tree

A tree is a hierarchy of connected nodes. Every node has exactly one parent except the root, which has none, and each node may have any number of children — so there are no cycles, only branches. The links between nodes are called edges.

Applications: file systems, and the Document Object Model of HTML and XML pages.

A binary tree limits each node to at most two children. A Binary Search Tree (BST) adds the ordering rule that makes search fast: for every node, all keys in its left subtree are smaller and all keys in its right subtree are larger.

Traversals (try each with the Travel button)

  • Depth-First
    • Pre-order: visit the node, then its left subtree, then its right.
    • In-order: left subtree, then the node, then right — on a BST this visits the keys in sorted order.
    • Post-order: left subtree, then right, then the node.
  • Breadth-First
    • Level-order: visit every node at one depth before moving to the next.
