Graph

A graph models things and the connections between them: a set of vertices (nodes) joined by edges (links). In an undirected graph an edge works both ways; in a directed graph each edge is a one-way arrow.

Applications: social networks, maps and routing, and machine learning.

A weighted graph attaches a number to each edge — a cost, distance, or capacity, depending on the problem.

Traversal (this demo is a directed graph)

  • Depth-First (DFS): follow one branch as far as it goes, then backtrack — naturally recursive, or stack-based.
  • Breadth-First (BFS): visit every neighbour before stepping further out, using a queue, so it reaches each node by the fewest edges from the start.

Both must track which nodes they have already seen, or a cycle would send them round forever. Because edges here are one-way, a traversal only follows arrows out of a node — a node with no inbound path from the start is never reached.
