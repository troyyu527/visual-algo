Stack

A stack is a linear collection of elements with a single point of access: the top. Elements are added and removed only there, never in the middle.

Operations

  • Push: place a new element on top of the stack.
  • Pop: remove and return the element currently on top.

The last element pushed is the first one popped — last in, first out (LIFO).

This reversing behaviour is exactly what powers function-call frames, undo history, and the backtracking in depth-first search.
