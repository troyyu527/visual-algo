Linked List

A linked list stores a sequence as a chain of nodes. Each node holds its own data plus a link (pointer) to the next node — so the nodes need not sit next to each other in memory.

Variants

  • Singly linked: each node points only to the next. Supports insertion, deletion, and traversal.
  • Doubly linked: each node also points back to the previous one, so the list can be walked in both directions.
  • Circular: the last node points back to the first instead of to null.

Because the nodes are linked rather than contiguous, inserting or removing one is cheap — just rewire a couple of pointers, with no shifting. The tradeoff: there is no random access — reaching the n-th node means walking the chain from the head.
