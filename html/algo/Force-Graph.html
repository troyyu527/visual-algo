3D Force-Directed Graph

A physics-based graph rendered in real 3D with WebGL (Three.js + d3-force-3d): nodes repel each other, edges act like springs, and the system relaxes into a shape in three dimensions. Drag to orbit, scroll to zoom, and drag a node to disturb the physics.

Pick a Source (blue) and a Target (pink) — use the Click sets dropdown, then click any node. Press Run to find the shortest route between them. BFS explores breadth-first; Dijkstra settles nodes in increasing distance and respects edge weights. Explored edges emit flowing particles, and the final Source→Target path lights up green.
